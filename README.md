# Job Post Analyzer

Part of my 30-day AI challenge.

A tool that takes a job posting and breaks it down — required skills, seniority,
red flags, and how well it matches a given resume.

## Status

Early work in progress.

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
